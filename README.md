# rag

Minimal Retrieval-Augmented Generation (RAG) prototype using `llamaindex`, Ollama embeddings, and a Chroma vector store.

Quick start

Install dependencies:

```bash
bun install
```

Run the example:

```bash
bun run index.ts
```
